# 🌦️ Weather App

A live Weather app built for **Prodigy InfoTech's Web Development Internship — Task 05**.

## 🔗 Live Demo
https://harshbitz.github.io/PRODIGY_WD_05/

## 📋 Features
- Search live weather by city name
- "Use My Location" via browser geolocation
- Dynamic background that shifts based on actual weather (sunny, rainy, snowy, stormy, cloudy)
- °C / °F unit toggle
- Displays temperature, condition, humidity, and wind speed

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
- [Open-Meteo API](https://open-meteo.com) (free, no API key required)

## 📂 Files
- `index.html` — page structure
- `style.css` — glassmorphic UI & weather-based themes
- `script.js` — geocoding, forecast fetching & unit conversion

## 🎯 What I Learned
Chaining two API calls (geocoding → forecast), mapping numeric weather codes to readable conditions, and converting units without re-fetching data.
